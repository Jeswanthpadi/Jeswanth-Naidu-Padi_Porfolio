# Jeswanth Naidu Padi - Portfolio

Personal portfolio website built with HTML, CSS and vanilla JavaScript.

## Local preview
Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment
The site is configured for GitHub Pages from the `main` branch and repository root. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.

## Sections
Home, selected projects, about and experience, education, research, skills, hackathon recognition, community and contact.
